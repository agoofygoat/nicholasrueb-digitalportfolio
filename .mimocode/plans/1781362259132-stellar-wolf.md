# Plan: Blueprint Portfolio — Full Rebuild

## Color System

### Problem
Current cream `#FEF3C7` is ugly. Blueprint blue `#2563EB` as a solid fill is flat and boring.

### Solution
**Dark blueprint base** with textured blues, not solid fills.

```
--bg-deep:        #0B1628    (page background — deep navy)
--bg-blueprint:   #0F1F3D    (card/section backgrounds — dark blue)
--grid-line:      rgba(100, 160, 255, 0.12)  (blueprint grid lines — NOT solid)
--grid-line-bold: rgba(100, 160, 255, 0.25)  (major grid lines every 5th)
--accent-blue:    #4D8BF5    (links, highlights — NOT #2563EB solid, use gradients)
--accent-glow:    rgba(77, 139, 245, 0.3)    (glow effects)
--text-primary:   #E8EDF5    (main text — off-white, not pure white)
--text-secondary: #8BA3C7    (secondary text — muted blue)
--text-dim:       #5A7396    (dimmed text)
--cream-warm:     #F0E6D3    (ONLY for cards/overlays — warm paper feel, used sparingly)
--kraft:          #C4A77D    (accent strokes, borders)
--white:          #FFFFFF
```

### Blueprint Background — NOT Solid
The background uses layered CSS, not a flat color:

```css
body {
  background-color: var(--bg-deep);
  background-image:
    /* Subtle noise grain */
    url("data:image/svg+xml,...noise..."),
    /* Blueprint grid — thin lines */
    repeating-linear-gradient(0deg,
      transparent, transparent 19px,
      rgba(100,160,255,0.07) 19px,
      rgba(100,160,255,0.07) 20px),
    repeating-linear-gradient(90deg,
      transparent, transparent 19px,
      rgba(100,160,255,0.07) 19px,
      rgba(100,160,255,0.07) 20px),
    /* Major grid lines every 100px */
    repeating-linear-gradient(0deg,
      transparent, transparent 99px,
      rgba(100,160,255,0.15) 99px,
      rgba(100,160,255,0.15) 100px),
    repeating-linear-gradient(90deg,
      transparent, transparent 99px,
      rgba(100,160,255,0.15) 99px,
      rgba(100,160,255,0.15) 100px),
    /* Radial glow in center */
    radial-gradient(ellipse at 50% 30%,
      rgba(77,139,245,0.08) 0%,
      transparent 70%);
}
```

This creates a dark blueprint paper with:
- Fine grid lines (20px) at 7% opacity
- Major grid lines (100px) at 15% opacity
- Subtle noise grain
- Radial blue glow in the hero area
- NO flat solid color anywhere

## Scroll Animations — Frame-by-Frame, Not Trigger-Pop

### Problem
Current animations are "pop in" — element invisible, scroll past threshold, element fades in. Feels like bubbles popping.

### Solution
**Scrub-linked animations** that play continuously as you scroll. The animation frame is tied to scroll position, not a trigger threshold.

### Animation Catalog

#### A. Hero — Blueprint Drawing Sequence
**Type:** Scroll-scrubbed, NOT triggered
**How it works:** As you scroll past the hero, the hero content animates in proportionally to scroll distance.

```
Scroll 0%:    Empty blueprint background, grid visible
Scroll 10%:   Blueprint crosshair SVG draws in (stroke-dashoffset animates)
Scroll 25%:   Title letters stagger in from bottom, one by one
Scroll 40%:   Caveat accent text "draws" itself like handwriting
Scroll 55%:   Subtitle fades in with slight upward drift
Scroll 70%:   Buttons slide in from left
Scroll 85%:   Blueprint decorative circles scale up
Scroll 100%:  Hero fully visible, continues parallaxing away
```

**Technical:**
```js
const heroTl = gsap.timeline({
  scrollTrigger: {
    trigger: '.hero',
    start: 'top top',
    end: 'bottom top',
    scrub: 1.5,  // <-- KEY: scrub links animation to scroll position
    pin: true    // pins hero while animation plays
  }
});
heroTl
  .from('.hero-crosshair svg', { strokeDashoffset: 500, duration: 0.3 })
  .from('.hero-title .char', { y: 80, opacity: 0, stagger: 0.02, duration: 0.3 }, 0.1)
  .from('.hero-accent', { clipPath: 'inset(0 100% 0 0)', duration: 0.2 }, 0.3)
  .from('.hero-subtitle', { y: 30, opacity: 0, duration: 0.2 }, 0.5)
  .from('.hero-actions .btn', { x: -40, opacity: 0, stagger: 0.05, duration: 0.2 }, 0.6);
```

#### B. Section Transitions — Blueprint Reveal Wipe
**Type:** Scroll-scrubbed clip-path
**How it works:** Each section reveals through a blueprint-style wipe — like unfolding a blueprint sheet.

```js
gsap.utils.toArray('.blueprint-reveal').forEach(section => {
  gsap.fromTo(section,
    { clipPath: 'polygon(0 0, 0 0, 0 100%, 0 100%)' },
    {
      clipPath: 'polygon(0 0, 100% 0, 100% 100%, 0 100%)',
      ease: 'none',
      scrollTrigger: {
        trigger: section,
        start: 'top 80%',
        end: 'top 30%',
        scrub: 0.8
      }
    }
  );
});
```

#### C. Text — Word-by-Word Reveal with Blueprint Underline
**Type:** Scroll-scrubbed
**How it works:** Section titles split into words. Each word fades in + slides up as you scroll. A blue underline draws across beneath.

```js
gsap.utils.toArray('.split-text').forEach(el => {
  const words = el.textContent.split(' ').map(w => `<span class="word-wrap"><span class="word">${w}</span></span>`);
  el.innerHTML = words.join(' ');
  
  gsap.from(el.querySelectorAll('.word'), {
    y: 40, opacity: 0,
    stagger: 0.08,
    ease: 'power2.out',
    scrollTrigger: {
      trigger: el,
      start: 'top 85%',
      end: 'top 50%',
      scrub: 0.5
    }
  });
});
```

#### D. Project Cards — Staggered Blueprint Unfold
**Type:** Scroll-scrubbed with stagger
**How it works:** Cards don't pop in. They "unfold" like blueprint sheets — scaling from center, rotating slightly, with stagger offset.

```js
gsap.utils.toArray('.bento-card').forEach((card, i) => {
  const delay = (i % 4) * 0.05;
  gsap.fromTo(card,
    { opacity: 0, scale: 0.85, rotationY: -10 },
    {
      opacity: 1, scale: 1, rotationY: 0,
      ease: 'power2.out',
      scrollTrigger: {
        trigger: card,
        start: 'top 90%',
        end: 'top 60%',
        scrub: 0.6
      }
    }
  );
});
```

#### E. Blueprint SVG Draw — Technical Drawing Animation
**Type:** Scroll-scrubbed SVG stroke
**How it works:** Large blueprint SVG elements (circles, crosshairs, dimension lines) draw themselves as you scroll past.

```js
gsap.utils.toArray('.bp-draw').forEach(svg => {
  const paths = svg.querySelectorAll('path, circle, line');
  paths.forEach(path => {
    const length = path.getTotalLength();
    gsap.set(path, { strokeDasharray: length, strokeDashoffset: length });
    gsap.to(path, {
      strokeDashoffset: 0,
      ease: 'none',
      scrollTrigger: {
        trigger: svg,
        start: 'top 85%',
        end: 'bottom 20%',
        scrub: 1
      }
    });
  });
});
```

#### F. Parallax Layers — Depth on Scroll
**Type:** Multi-speed parallax
**How it works:** Different elements scroll at different speeds creating depth.

```js
// Blueprint grid background — slowest
gsap.to('.bp-grid-bg', {
  y: -100,
  ease: 'none',
  scrollTrigger: { trigger: 'body', start: 'top top', end: 'bottom bottom', scrub: 2 }
});

// Decorative shapes — medium speed
gsap.utils.toArray('.geo-deco').forEach((el, i) => {
  gsap.to(el, {
    y: -60 * (i % 3 + 1),
    rotation: 180 * (i % 2 === 0 ? 1 : -1),
    ease: 'none',
    scrollTrigger: { trigger: el, start: 'top bottom', end: 'bottom top', scrub: 1.5 }
  });
});

// Content — normal speed (default)
```

#### G. Skill Cards — 3D Flip Reveal
**Type:** Scroll-triggered 3D flip
**How it works:** Skill cards start face-down and flip to face-up as you scroll to them.

```js
gsap.utils.toArray('.skill-card').forEach((card, i) => {
  gsap.fromTo(card,
    { rotationX: 90, opacity: 0 },
    {
      rotationX: 0, opacity: 1,
      transformPerspective: 600,
      ease: 'back.out(1.7)',
      scrollTrigger: { trigger: card, start: 'top 85%' },
      delay: i * 0.08
    }
  );
});
```

#### H. Timeline — SVG Path Draw + Items Cascade
**Type:** Scrubbed SVG line + staggered items
**How it works:** The timeline's connecting line draws itself as you scroll, and items cascade in from alternating sides.

```js
const timelinePath = document.querySelector('.timeline-path');
if (timelinePath) {
  const length = timelinePath.getTotalLength();
  gsap.set(timelinePath, { strokeDasharray: length, strokeDashoffset: length });
  gsap.to(timelinePath, {
    strokeDashoffset: 0,
    ease: 'none',
    scrollTrigger: { trigger: '.timeline', start: 'top 70%', end: 'bottom 30%', scrub: 1 }
  });
}

gsap.utils.toArray('.timeline-item').forEach((item, i) => {
  gsap.fromTo(item,
    { opacity: 0, x: i % 2 === 0 ? -60 : 60, scale: 0.9 },
    {
      opacity: 1, x: 0, scale: 1,
      ease: 'power2.out',
      scrollTrigger: { trigger: item, start: 'top 85%', end: 'top 60%', scrub: 0.5 }
    }
  );
});
```

#### I. Social Cards — Bounce-Stagger Entrance
**Type:** Scroll-triggered with elastic bounce
**How it works:** Social cards bounce in from below with stagger, overshooting slightly.

```js
gsap.utils.toArray('.social-card').forEach((card, i) => {
  gsap.fromTo(card,
    { y: 80, opacity: 0, scale: 0.8 },
    {
      y: 0, opacity: 1, scale: 1,
      ease: 'elastic.out(1, 0.5)',
      scrollTrigger: { trigger: card, start: 'top 90%' },
      delay: i * 0.12
    }
  );
});
```

#### J. Mouse-Driven 3D Card Tilt
**Type:** Mousemove, NOT scroll
**How it works:** Cards tilt toward the mouse cursor in 3D, with perspective.

```js
document.querySelectorAll('.bento-card, .social-card').forEach(card => {
  card.addEventListener('mousemove', e => {
    const rect = card.getBoundingClientRect();
    const x = (e.clientX - rect.left) / rect.width - 0.5;
    const y = (e.clientY - rect.top) / rect.height - 0.5;
    gsap.to(card, {
      rotationY: x * 15,
      rotationX: -y * 15,
      transformPerspective: 800,
      duration: 0.3,
      ease: 'power2.out'
    });
  });
  card.addEventListener('mouseleave', () => {
    gsap.to(card, {
      rotationY: 0, rotationX: 0,
      duration: 0.5,
      ease: 'elastic.out(1, 0.5)'
    });
  });
});
```

## Project Grid — Bento Layout

### Current Problem
`grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))` — all cards same size. Boring.

### New: Asymmetric Bento Grid
```css
.bento-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  grid-auto-rows: 200px;
  gap: 16px;
}

/* Featured project — large card */
.bento-card.featured {
  grid-column: span 2;
  grid-row: span 2;
}

/* Wide card */
.bento-card.wide {
  grid-column: span 2;
}

/* Tall card */
.bento-card.tall {
  grid-row: span 2;
}

/* Default — 1x1 */
.bento-card {
  grid-column: span 1;
  grid-row: span 1;
}
```

Layout:
```
┌──────────┬──────────┬──────┐
│          │          │      │
│ Featured │ Featured │  A   │
│  (2x2)   │  (2x2)   │      │
│          │          ├──────┤
├──────┬───┤          │  B   │
│  C   │ D │──────────┤      │
│(1x1) │(1)│    E     ├──────┤
├──────┴───┤  (2x1)   │  F   │
│    G     │──────────┤(1x2) │
│  (2x1)   │    H     │      │
└──────────┤  (2x1)   └──────┘
           └──────────┘
```

Each card has:
- Blueprint SVG background (varied per card)
- Handwritten Caveat label ("favorite", "newest", etc.)
- 3D tilt on hover
- Stroke-draw animation on scroll
