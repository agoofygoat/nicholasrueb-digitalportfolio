# nicholasrueb-digitalportfolio

A digital portfolio framework for Nicholas Rueb.

## Getting started

Open `index.html` in a browser to preview the portfolio.

## Structure

- `index.html` — main portfolio page with sections for projects, activities, contributions, and contact
- `styles.css` — responsive UX-focused styling and animations
- `script.js` — interactive navigation and project filtering

## Customization

Update the placeholder project links and content in `index.html` to showcase your own coding, robotics, and engineering work.
